- AI Assistant Dashboard - Flutter

Une interface de gestion de tâches conçue avec Flutter. Ce projet reproduit un dashboard complet avec suivi de progression, statistiques de tâches et gestion de projets assistée par IA.

- Fonctionnalités
    *Dashboard Interactif* : Visualisation globale des tâches prioritaires et en retard.
    *Graphique de Progression* : Analyse visuelle des statistiques via un donut chart (utilisant `fl_chart`).
    *Timeline Dynamique* : Navigation horizontale pour la sélection des dates.
    *Gestion des Deadlines* : Liste des projets en cours avec indicateurs de statut colorés.
    *Design Responsive* : Adapté aux mobiles et aux navigateurs web.


- Architecture du Projet
    Le projet suit une architecture propre:
    - `core/` : Constantes de couleurs et thèmes.
    - `features/` : Logique métier et interface par fonctionnalité (ex: dashboard).
    - `shared/` : Widgets et composants réutilisables sur toute l'application.
