# TP Flutter – Dashboard (Tableau de bord)

## 📱 Description du projet

Ce projet est une application **Flutter** qui représente un **tableau de bord (Dashboard)**.
Il a été réalisé dans le cadre d’un **TP Flutter** afin de pratiquer la création d’interfaces
utilisateur avec Flutter.

L’application affiche différentes sections :
- Des cartes de statistiques des tâches
- La progression des tâches (Task Progress)
- Une liste des deadlines
- Une timeline des tâches
- Une barre de navigation en bas de l’écran

Le projet a été réalisé en utilisant **un seul fichier principal (`main.dart`)** afin de rester
simple et compréhensible pour un niveau débutant.

---

## 🧩 Fonctionnalités principales

- Interface moderne inspirée d’un design mobile
- Cartes :
  - Priority Task
  - Overdue Task
  - Upcoming Task
  - Pending Task
- Section **Task Progress** avec un cercle de progression
- Section **Deadlines** avec le statut des projets
- Section **Tasks Timeline**
- Barre de navigation (Bottom Navigation Bar)

---

## 🛠️ Technologies utilisées

- **Flutter**
- **Dart**
- Widgets Flutter de base (`Scaffold`, `Column`, `Row`, `Container`, etc.)
